### Java类

-   类: 类是一个模板，它描述一类对象的行为和状态

语义上表达的是一类实体(对象)的抽象， 在Java中的惯例是一个文件中存放一个public类

### Java对象

-   对象: 对象是类的一个实例

语义上是表达一个java类的实体, 对象是一般情况下Java语言里的”一等公⺠” ，对象可以赋值到一个变量，通过new语句进行创建

### Java方法和成员变量

-   方法：类中定义的该类的实例对象所具有的行为

一个方法由"方法名 + 参数类型"确定， 相同的方法名、不同的参数类型是不同的方法

成员变量是对象或者类中的变量，其作用域在类中,或对象中。可以用修饰符控制方法或成员变量的作用域

### 修饰符

-   修饰符用于控制变量, 类 的作用域和一些访问限制
