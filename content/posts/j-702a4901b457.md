### 1、form表单有什么作用？有哪些常用的input 标签，分别有什么作用？

-   from表单：用户通过输入内容到表单并提交向服务器传输数据，从而实现用户与web服务器的交互。
-   <input> 标签用于搜集用户信息。根据不同的 type 属性值，输入字段拥有很多种形式。可以是文本字段（text）、复选框（checkbx）、单选按钮（radio）、按钮（button）、提交按钮（submit）、密码字段（password)等等

常用的属性有：

-   checked-> 规定此 input 元素首次加载时应当被选中
-   name-> 定义 input 元素的名称
-   value-> 规定 input 元素的值

### 2、post 和 get 方式的区别？

在from表单中有一个method属性，定义提交表单中的数据给服务器的方式，其中我们常用的有get和post两种方式，二者区别如下：

1、 get方式发送请求是会将表单所有数据拼接成key=value的形式，拼接在URL中向服务器传输信息；post方式发送请求时浏览器URL并不发生变化，但数据会通过浏览器后台传输给服务器，  
2、get方式发送请求时的URL为表单数据的拼接，如果输入的是密码，则密码会显示在url上，不安全；post方式发送请求时浏览器URL并不发生变化，安全性更可靠  
3、浏览器地址栏的url链接的长度有限制，如果采用get方式；而表单输入信息过多，会导致请求拼装的URL超出长度限制，采用post方式不会有表单数据长度的限制，故post适用于数据的增加和修改故  
4、Get是用来从服务器上获得数据，而post是用来向服务器上传递数据  
如果提交请求纯粹只是从服务器端获取数据而不是进行其他操作，并且多次提交不会有明显的副作用，应该使用get（适用于数据的查询获取）。  
如果提交这个请求会产生其他操作和影响，就应该使用post（适用于数据的增删改）。  
如：修改服务器上数据库中的数据；发送一封邮件；删除一个文件等

### 3、在input里，name 有什么作用？

-   定义 input 元素的名称。在post或者get的时候，name和input中的value值形成 键值对，同时服务器端的表单处理程序通过对name进行操作获取相应的用户输入

### 4、radio 如何分组?

为属于同一组(类别)的选项设置相同的name值,如

```
<input type="radio" name="gender" value="male">男
<input type="radio" name="gender" value="female">女
```

### 5、placeholder属性的作用

-   占位符，即规定输入文本字段之前的显示的值
-   适用与以下的输入类型：text、url、email、tel、password

### 6、type=hidden隐藏域的作用？请举例说明

-   标签<input type="hidden" name="" value="">标签的作用是：隐藏不想让用户看到的信息，但是这些信息对于Web应用又是非常必要的。
    
    -   暂存信息：后端在构造web页面的过程中，通过hidden隐藏域在页面中添加了相关数据信息(用户对网页进行操作时可能会用到这些数据信息)
    -   信息安全：后端在构造web页面的过程中，可以通过hidden隐藏域在页面中添加相关的验证信息，当form表单被提交后，服务器会收到该验证信息，通过一定的算法校验该验证信息，可以有效防止非法请求对数据库的增删改查，提高了web应用的安全性。
