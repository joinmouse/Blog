-   AMD是RequireJS在推广过程中对模块化定义的规范化产出

```
define(['package/lib',function(lib){ 
}])
```

-   CMD是SeaJS在推广过程对模块定义的规范化产出

```
define(function(require, export, module){
})
```

-   CommonJS规范-module.export 前端浏览器并不支持，是后端node产生的规范

```
export.area = function(r) {
  return Math.PI * r * r
}
```
